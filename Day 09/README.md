# Python Mini Projects

This repository contains basic Python mini projects created for learning and practice. The programs focus on beginner-friendly concepts such as user input, string handling, random number generation, and conditional statements.

## Projects Included

### 1. Word Counter
This program takes a sentence from the user and counts the total number of words in it. It uses Python string methods to split the sentence into words and then displays the count.

**Concepts used:**
- user input
- strings
- `split()` method
- `len()` function

### 2. Number Guessing Game
This program generates a random number and asks the user to guess it. If the guessed number matches the generated number, the user wins; otherwise, the program shows the correct number.

**Concepts used:**
- random module
- user input
- conditional statements
- basic game logic

## Technologies Used
- Python
- String Handling
- Random Module
- Conditional Statements

## Purpose
These mini projects were created to improve basic Python programming skills and to practice simple problem-solving through interactive programs.
