# Expense Splitter

A Python program that calculates the total shared expense among multiple people and finds how much each person should pay equally.

## Features
- Takes expenses from multiple people
- Calculates total amount
- Splits the expense equally
- Simple and useful real-life project

# Countdown Timer

A Python program that counts down from the number of seconds entered by the user and displays the remaining time in MM:SS format.

## Features
- Takes time input in seconds
- Converts into minutes and seconds
- Updates countdown every second
- Displays final message when time ends
