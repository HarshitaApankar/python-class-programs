# Text-to-Emoji Converter

A simple Python project that converts specific words in a sentence into emojis. The program takes user input, searches for predefined words such as "happy", "sad", "love", and "cool", and replaces them with their corresponding emojis.

## Features
- Takes user input
- Uses Python dictionaries
- Replaces words with emojis
- Case-insensitive input handling

## Technologies Used
- Python
- Dictionary
- Loops
- String Manipulation

## Example

Input:
I am happy and cool

Output:
I am 😊 and 😎

# Random Password Generator

A Python program that generates strong random passwords based on the length provided by the user. The password contains a mix of uppercase letters, lowercase letters, numbers, and special characters.

## Features
- User-defined password length
- Random password generation
- Includes letters, digits, and symbols
- Simple and secure design

## Technologies Used
- Python
- Random Module
- String Module
- Loops

## Example

Input:
8

Output:
A7@kP2#z
